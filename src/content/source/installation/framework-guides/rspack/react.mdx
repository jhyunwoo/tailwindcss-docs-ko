<h2 id="create-your-project">Create your project</h2>

<p>Start by creating a new Rspack project if you don’t have one set up already. The most common approach is to use <a href="https://rspack.dev/guide/start/quick-start#using-the-rspack-cli">Rspack CLI</a>.</p>

```shell
npm create rspack@latest
```

<h2 id="install-tailwind-css">Install Tailwind CSS</h2>

<p>Install <code>@tailwindcss/postcss</code> and its peer dependencies.</p>

```shell
npm install tailwindcss @tailwindcss/postcss postcss postcss-loader
```

<h2 id="enable-postcss-support">Enable PostCSS support</h2>

<p>In your <code>rspack.config.js</code> file, enable the PostCSS loader. See <a href="https://rspack.dev/guide/tech/css#tailwind-css">the documentation</a> for more information.</p>

```ts
export default defineConfig({
  // ...
  module: {
    rules: [
      // [!code highlight:6]
      {
        test: /\.css$/,
        use: ["postcss-loader"],
        type: "css",
      },
      // ...
    ],
  },
}
```

<h2 id="configure-postcss-plugins">Configure PostCSS Plugins</h2>

<p>Create a <code>postcss.config.mjs</code> file in the root of your project and add the <code>@tailwindcss/postcss</code> plugin to your PostCSS configuration.</p>

```js
export default {
  plugins: {
    // [!code highlight:2]
    "@tailwindcss/postcss": {},
  },
};
```

<h2 id="import-tailwind-css">Import Tailwind CSS</h2>

<p>Add an <code>@import</code> to <code>./src/index.css</code> that imports Tailwind CSS.</p>

```css
@import "tailwindcss";
```

<h2 id="start-your-build-process">Start your build process</h2>

<p>Run your build process with <code>npm run dev</code>.</p>

```shell
npm run dev
```

<h2 id="start-using-tailwind-in-your-project">Start using Tailwind in your project</h2>

<p>Start using Tailwind’s utility classes to style your content.</p>

```jsx
export default function App() {
  return (
    // [!code highlight:4]
    <h1 className="text-3xl font-bold underline">
      Hello world!
    </h1>
  )
}
```
